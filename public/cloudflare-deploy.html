Deployment Guide

Cloudflare Pages Deployment

This SDLC workflow site is static. Publish the public folder to Cloudflare Pages.

Option 1: Cloudflare Dashboard

  1. Open the Cloudflare Dashboard.
  2. Go to Workers & Pages.
  3. Create a Pages project.
  4. Connect this Git repository.
  5. Use the build settings below.
  6. Deploy.
  7. Add your custom domain in the Pages project settings if needed.
Setting Value
Framework preset None
Build command Leave blank
Build output directory public
Root directory /

Option 2: Wrangler CLI

From this repo:

npm run deploy:cloudflare -- --project-name <your-pages-project-name>

If Wrangler asks you to log in:

npx wrangler login

Notes

  • server.js is only for local preview with npm start.
  • Cloudflare Pages serves files directly from public.
  • Query URLs like ?status=in-test work because the app is a static single page.
  • Security headers are defined in public/_headers.
